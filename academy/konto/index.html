Mit Microsoft Authenticator, Google Authenticator, 1Password oder einer kompatiblen TOTP-App scannen. Der QR-Code wird ausschließlich lokal im Browser erzeugt.

QR-Code scannen und bestätigen

Authenticator-App öffnen → Konto hinzufügen → QR-Code scannen. Anschließend den dort angezeigten 6-stelligen Code unten eingeben.

Manuellen Schlüssel anzeigen

Nur verwenden, wenn die App keinen QR-Code scannen kann. Der Schlüssel wird nur während dieser Einrichtung angezeigt.

Recovery-Codes – nur einmal sichtbar
