Vertiefung öffnen

Binary ist kein „sichtbarer String“

n8n verwaltet Dateiinhalt separat und referenziert ihn über ein Binary Property wie data. JSON kann gleichzeitig Dateikontext enthalten: Dokumenttyp, Kunde, Quelle oder Workflow-State.

Item.json+Item.binary.data→File Node / Upload / Parser
Base64

Base64 ist lediglich eine Textdarstellung von Bytes. Es ist keine Verschlüsselung und erzeugt zusätzlichen Größen-Overhead.

Parser-Konfiguration gehört zum Datenvertrag

CSV braucht Delimiter, Header- und Encoding-Regeln. Spreadsheet braucht Sheet/Range. PDF braucht Extraktionsstrategie. Falsche Parser-Annahmen können einen technisch „erfolgreichen“ aber fachlich falschen Output erzeugen.

06
ENCODING

UTF-8, BOM und internationale Zeichen

Encode und Decode müssen zusammenpassen

Wird UTF-8 mit einer falschen Codepage gelesen, entstehen typische Mojibake-Symptome. Teste Umlaute und Türkçe Zeichen bewusst – nicht nur ASCII-Namen.

09
UPLOAD SECURITY

Extern hochgeladene Files sind untrusted input

Dateigröße, Typ, Pfad, Inhalt und Malware-Risiko müssen begrenzt werden, bevor teure Verarbeitung startet.

1 · Sizeharte Obergrenze
2 · Typeallowlist + parse
3 · Nameserverseitig normalisieren
4 · Scanje nach Risiko malware/quarantine
Vertiefung öffnen

Path Traversal und Resource Exhaustion vermeiden

Dateinamen wie ../../something dürfen keinen Storage-Pfad bestimmen. Sehr große Dateien dürfen nicht ungeprüft in RAM geladen werden. Verwende generierte Object Keys, Size Limits, sichere temporäre Bereiche und Quarantine.

Zip Bomb / oversized file: Kleine Upload-Größe kann bei Dekompression riesig werden. Wenn Archive erlaubt sind, muss auch entpackte Größe begrenzt werden.

Content Hash ist stärker als Dateiname

Zwei Dateien können denselben Namen haben, aber unterschiedlichen Inhalt – oder unterschiedliche Namen, aber identische Bytes. Ein SHA-256 Hash kann Integritätsprüfung, Dedupe und Audit unterstützen.

Privacy

Object Storage braucht Access Policies, Encryption at Rest, Lifecycle/Retention und keine öffentlichen URLs als Default.
